# 小智AI助手 Android/iOS 客户端

基于Flutter框架开发的小智AI助手，支持多平台（iOS、Android、Web、Windows、macOS、Linux）部署，提供实时语音交互和文字对话功能。

> 基于原项目 TOM88812/xiaozhi-android-client 构建，仅供个人学习使用。

### 功能特性

| 功能 | 状态 | 描述 |
|------|------|------|
| **语音对话** | ✅ | 实时语音交互 |
| **文字对话** | ✅ | 文字输入对话 |
| **实时打断** | ✅ | 说话时可随时打断 |
| **Live2D** | ✅ | 多模型切换 |
| **MCP调用** | ✅ | 支持MCP能力调用 |
| **IoT控制** | ✅ | 调用手机功能、导航、听歌等 |
| **多服务** | ✅ | 支持WS和MQTT协议 |
| **多平台** | ✅ | iOS / Android / Web / Windows / macOS / Linux |

### 下载

从 [Releases](https://github.com/1366214813/xiaozhi-ios-build/releases/latest) 页面下载：
- **iOS**: `lhht-ai-assistant.ipa`（未签名，需 TrollStore 或 ESign）
- **Android**: `lhht-app-debug.apk`（直接安装）

### 使用说明

1. 首次进入需配置服务器
2. 不勾选自定义服务器 = 使用虾哥服务器（xiaozhi.me）
3. 勾选自定义服务器 = 需手动配置 WS 地址、MAC 地址、OTA 地址
